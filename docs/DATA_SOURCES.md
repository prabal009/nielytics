# External data sources — verification and access

Verification on 2026-10-29 used explicit HTTP requests to the **specified** endpoints; no network request runs at package import. A successful sample response verifies parsing of that sample, not continuous availability, complete coverage, official warning status, or commercial usage rights.

| Source | Endpoint | Verification | Interpretation |
| --- | --- | --- | --- |
| Open-Meteo historical | https://archive-api.open-meteo.com/v1/archive | HTTP 200, daily sample 2025-01-01–03 with temperature °C and precipitation mm | Historical modeled/reanalysis weather, **not** live observations or forecasts |
| Open-Meteo flood | https://flood-api.open-meteo.com/v1/flood | HTTP 200, daily `river_discharge` m³/s sample | Modeled river discharge, **not** observed inundation; implemented requests restrict dates to the past |
| NASA POWER | https://power.larc.nasa.gov/api/temporal/daily/point | HTTP 200, `PRECTOTCORR` mm/day and `T2M_MAX` °C, daily keys, `header.fill_value=-999`, time standard LST | Historical estimated meteorology; missing sentinel maps to null |
| NOAA IBTrACS NI | https://www.ncei.noaa.gov/data/international-best-track-archive-for-climate-stewardship-ibtracs/v04r01/access/csv/ibtracs.NI.list.v04r01.csv | HTTP 200, header plus second units row; `SID`, `ISO_TIME`, `LAT`, `LON`, `WMO_WIND` (knots) | Historical cyclone fixes, not landfall, damage, or live alerts |

The landing page says current as of March 7, 2016 although CSV includes later-dated rows; date coverage is reported from actual records and must not imply freshness. |

Open-Meteo documentation: [historical](https://open-meteo.com/en/docs/historical-weather-api), [flood](https://open-meteo.com/en/docs/flood-api), [terms](https://open-meteo.com/en/terms). NASA POWER: [daily API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/). IBTrACS: [product](https://www.ncei.noaa.gov/products/international-best-track-archive), [column definitions](https://www.ncei.noaa.gov/sites/default/files/2025-09/IBTrACS_v04r01_column_documentation.pdf).

Public sampled endpoints did not request API credentials. Check each provider's **current** licensing, attribution, update cadence, rate limits, coverage, and access terms independently before production or commercial use; HTTP 200 does not grant a license. Do not substitute an invented NASA endpoint when the specified COOLR service fails. Indian government datasets require their own documented access/authorization; no government API is claimed. Sampled historical weather and event inventories are not warning feeds.

`HTTPClient` accepts an injected opener and clock/sleep, explicit timeout/retry/backoff, optional cache directory and TTL, and `offline`/`allow_expired_offline` policies. The default cache is disabled; when enabled, retrieval/expiration metadata must accompany the response. Normal pytest uses mocked responses and does not call live providers. Explicit online calls can fail with HTTP, timeout, schema, or rate-limit errors; backend callers must handle these rather than replace unavailable observations with zero.

NASA GLC export requires explicit acceptance of the [catalog terms](https://data.nasa.gov/dataset/global-landslide-catalog-export) via `fetch_landslide_events(accept_terms=True)`, or `load_landslide_catalog(local_path)` for offline CSV use. Cite Kirschbaum et al. (2010, DOI 10.1007/s11069-009-9401-4) and Kirschbaum et al. (2015, DOI 10.1016/j.geomorph.2015.03.016) per catalog guidance. The [NASA data resource](https://data.nasa.gov/dataset/global-landslide-catalog-export/resource/7dc0d8c1-05f6-4c5c-8fee-20834e4d5d31) does not state a reuse license: review the export terms before distribution/commercial use. Incomplete coordinates remain null in records and are explicitly counted when exporting map points. COOLR remains unavailable at the specified service URL; no layer ID was invented.
