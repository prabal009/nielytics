# Backend team handoff — NIElytics library

1. Install this repository or its built wheel into **your own backend virtual environment**: `python -m pip install /path/to/nielytics`. The standard install includes all currently implemented runtime features; development tools are not included.
2. Import `Dataset`, plotting functions, `AnalysisResult`, and five hazard analyzers from `nielytics`. Instantiate a Dataset from a trusted path or DataFrame; cleaning returns a new Dataset. Use `profile()`/`to_records()` for strict JSON and `summary()` for native pandas results.
3. Import `HTTPClient` and explicitly selected historical functions from `nielytics.climate.providers`. Configure timeout, bounded retries, optional cache directory/TTL and offline policy. Provider results expose `data['records']` plus source/time/units metadata. Do not treat modeled discharge as observed flooding, historical catalogs as live warnings, or unknown values as zero.
4. Compute indicators from your supplied DataFrame with explicit units: `HeatwaveAnalyzer(frame, unit='C')`, `FloodAnalyzer(frame, unit='mm')`, `DroughtAnalyzer(frame, unit='mm')`, `CycloneAnalyzer(tracks, wind_unit='km/h', pressure_unit='hPa')`, and `LandslideAnalyzer(frame, rainfall_unit='mm', slope_unit='degrees')`. Invoke supported methods in [API reference](api_reference.md); all return `AnalysisResult.to_dict()` for backend JSON. `examples/climate_indicators.py` exercises all five using **synthetic** values; not real hazard observations.
5. For maps, import `points_to_geojson`, `tracks_to_geojson`, `regions_to_geojson`, or `get_hazard_map_layer` from `nielytics.geospatial`. Provide actual vector inputs and provenance. GeoJSON is EPSG:4326, `[longitude, latitude]`; unknown boundaries and landfall points are never generated. See [GeoJSON guide](GEOJSON_GUIDE.md).
6. For charts, import `plot_line` etc. from `nielytics`; Plotly figures serialize with `.to_json()` or `.write_html(..., auto_open=False)`, geographic Matplotlib figures with `.savefig()`. Nothing opens a window or contacts the network on import.
7. Catch `NIElyticsError`, and provider-specific `ProviderError`, `ResponseError`, `OfflineCacheError` at your boundary; choose your own error/HTTP contract and avoid exposing local paths. Teammates own auth, routes, persistence, map rendering, and deployment. A configured `ClimateAnalytics` facade or arbitrary region lookup is **not implemented**; never call it.

See [integration contract](../INTEGRATION_CONTRACT.md), [commands](../COMMANDS_AND_USAGE.md), and [data-source evidence](DATA_SOURCES.md). Source availability, licensing, competition eligibility, and required attribution must be checked independently.
